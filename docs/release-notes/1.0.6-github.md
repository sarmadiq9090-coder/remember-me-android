## Remember Me for Android 1.0.6

### New
- **F-Droid build:** `RememberMe-1.0.6-fdroid.apk` is the same app without the self-updater and without the INTERNET, ACCESS_NETWORK_STATE and REQUEST_INSTALL_PACKAGES permissions. It has the same application id and is signed with the same key as `RememberMe-1.0.6.apk`.
- Store metadata for F-Droid and IzzyOnDroid (`fastlane/metadata`).

### Install
- Normal users: keep using `RememberMe-1.0.6.apk` (it updates itself from GitHub as before). It installs over 1.0.5 and your reminders stay.
- Use the `-fdroid` file only if you want an app that can never connect to the internet.
